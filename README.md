# 刷题系统

这是一个本地静态刷题系统，可以直接用浏览器访问。系统内置多门课程题库，支持练习、背题、考试、错题、收藏和本地进度保存。

- 题目总数：598 题
- 新增科目：植物生理学

## 主要功能

- 题库多选：可以按科目或题库组合练习。
- 练习模式：每题提交后立即显示答案和解析。
- 背题模式：直接展示答案，适合快速复习。
- 考试模式：完成后统一交卷并统计正确率。
- 错题与收藏：错题、收藏和练习进度保存在当前浏览器本地。
- 图片题支持：题干、选项和答案可显示题目图片。

## 运行方式

本项目是静态网页，不需要后端服务。进入项目目录后运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:8765/
```

输入访问密码 `赵喆` 后即可进入系统。

## 目录说明

- `index.html`：系统入口页面。
- `app.js`：刷题逻辑、访问验证、模式切换、错题与收藏逻辑。
- `styles.css`：页面样式。
- `data/question-banks.json`：完整题库数据。
- `data/question-banks.js`：浏览器直接加载的静态题库数据。
- `data/custom-banks/`：自定义题库源数据。
- `assets/questions/`：题目图片资源。

## 部署说明

可以把整个目录上传到任意静态网站服务，例如 Nginx、GitHub Pages 或普通 HTTP 文件服务。只要能访问 `index.html`，系统就可以运行。

本仓库保存的是可直接部署的服务器包内容，不包含题库生成脚本和开发过程中的临时文件。
